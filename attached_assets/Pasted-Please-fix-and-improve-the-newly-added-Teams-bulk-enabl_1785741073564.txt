If `setUsers` is actually a custom asynchronous persistence function, verify this from its implementation. If so, rename or document it clearly to avoid confusion with a normal React state setter.

## 2. Avoid replacing the entire users collection where possible


This is important because another administrator could update a user at the same time.

## 5. Correct success and failure handling

Do not show a success toast unless persistence has completed successfully.

Use this behaviour:

### On success

* Update local user state
* Show the number of users updated
* Close the modal
* Reset the saving state

Example message:

```text
Teams pings enabled for 42 users
```

or:

```text
Teams pings disabled for 42 users
```

### On failure

* Show a destructive error toast
* Keep the modal open so the administrator can retry
* Do not apply a misleading local-only update
* Log the actual error for debugging
* Reset the saving state

Do not close the modal after a failed update.

Use `finally` to ensure the saving state is always reset.

Suggested structure:

```js
setTeamsBulkSaving(true);

try {
  await persistBulkTeamsPreference(...);

  setUsers(updatedUsers);

  toast({
    title: enabling
      ? `Teams pings enabled for ${eligibleUsers.length} users`
      : `Teams pings disabled for ${eligibleUsers.length} users`,
  });

  setTeamsBulkConfirm(null);
} catch (error) {
  console.error(
    'Failed to bulk-update Teams notification preferences',
    error
  );

  toast({
    title: 'Failed to update Teams notification preferences',
    description: 'No changes were applied. Please try again.',
    variant: 'destructive',
  });
} finally {
  setTeamsBulkSaving(false);
}
```

Use the project’s existing logger instead of `console.error` if one is available.

## Suggested implementation shape

Adapt this to the project’s actual persistence utilities:

```jsx
const eligibleTeamsUsers = useMemo(
  () =>
    (users || []).filter(
      user => !user.archived && user.active !== false
    ),
  [users]
);

const handleTeamsBulkUpdate = async () => {
  if (!teamsBulkConfirm || teamsBulkSaving) return;

  const enabling = teamsBulkConfirm === 'enable';

  if (eligibleTeamsUsers.length === 0) {
    toast({
      title: 'No eligible users',
      description: 'There are no active users to update.',
      variant: 'destructive',
    });
    return;
  }

  setTeamsBulkSaving(true);

  try {
    await persistBulkTeamsNotificationPreference({
      userIds: eligibleTeamsUsers.map(user => String(user.id)),
      enabled: enabling,
    });

    const eligibleIds = new Set(
      eligibleTeamsUsers.map(user => String(user.id))
    );

    const updatedUsers = (users || []).map(user =>
      eligibleIds.has(String(user.id))
        ? {
            ...user,
            teamsNotificationsEnabled: enabling,
          }
        : user
    );

    setUsers(updatedUsers);

    toast({
      title: enabling
        ? `Teams pings enabled for ${eligibleTeamsUsers.length} users`
        : `Teams pings disabled for ${eligibleTeamsUsers.length} users`,
    });

    setTeamsBulkConfirm(null);
  } catch (error) {
    console.error(
      'Failed to bulk-update Teams notification preferences',
      error
    );

    toast({
      title: 'Failed to update Teams notification preferences',
      description: 'No changes were applied. Please try again.',
      variant: 'destructive',
    });
  } finally {
    setTeamsBulkSaving(false);
  }
};
```

Do not create a placeholder persistence function without connecting it to the real backend implementation.
