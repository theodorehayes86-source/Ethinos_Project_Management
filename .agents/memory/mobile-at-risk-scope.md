description: User's required default for per-person task groups in the mobile team view

Per-person task groups in mobile At Risk must default to collapsed, with the person's name and pending count visible.

**Why:** The user repeated that the default should be collapsed.

**How to apply:** Preserve this default for Overdue and Due Today when revising the team view; reveal the tasks only when the user expands a person.
