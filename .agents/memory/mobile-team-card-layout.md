---
name: Mobile team-card layout
description: User's priority for full names and compact team-member cards on mobile
---

Mobile team-member cards must show the full person's name. Compact the avatar,
badges and other graphics instead of truncating names or letting badges become
tall stacked labels.

**Why:** The user reported a truncated name and an overly tall card and explicitly
asked for names to stay visible while graphics shrink.

**How to apply:** Give names priority over decorative elements. Keep task counts
and actions compact and readable; allow unusually long names to wrap rather than
hide text.
